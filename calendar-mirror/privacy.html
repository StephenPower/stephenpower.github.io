calendar-mirror privacy policy

Last updated: 2026-09-15

calendar-mirror is a personal utility operated by its sole user, Stephen Power. It is not a commercial service and is not available to anyone else.

What it does

The application writes meeting titles, times, and meeting links into a dedicated "Work Mirror" calendar inside the owner's own Google account, using the Google Calendar API. It runs on the owner's own computer when the owner starts it.

Data

  • The only Google account it accesses is the owner's own account, with the owner's explicit consent.
  • Calendar data is written to, and read from, that one account. Nothing is sent to any third party.
  • The OAuth token is stored locally on the owner's computer and nowhere else.
  • No analytics, advertising, or tracking of any kind.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
